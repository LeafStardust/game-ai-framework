# Balatro Strategy Contributions

Canonical component/state -> Bond contribution values after **Catalogue Audit Pass 2**. Architecture is in `BALATRO_STRATEGY_SYSTEM.md`; identities/unlocks are in `BALATRO_STRATEGY_CATALOGUE.md`.

## Rules

- One shared weighted pool per Bond; contributors are additive alternatives, never sequential rank keys.
- Rank measures development only; realization and Build Health remain separate.
- Multi-Bond contribution is intentional only when the component genuinely develops each axis; overlap is not itself an error.
- Hard-unlock Bonds return `LOCKED` when the defining payoff is absent; support/history cannot manufacture the Bond.
- Generic enabling mechanics do not receive quota merely because they can participate in a hand. They belong to tactical/motif valuation unless they genuinely develop that Bond.
- Values remain provisional Red/White calibration pending telemetry calibration.

## Audit Pass 2 overlap conclusions

- Duplicate contribution is allowed only where the same component genuinely advances multiple independently meaningful axes: e.g. Baron -> Held Cards + Kings; Hack -> Played Retrigger + Low Ranks; Sock and Buskin -> Face Cards + Played Retrigger; DNA -> Deck Growth + rank-concentration Bonds.
- This does **not** double-count score. Bond rank is structural evidence; Build Health/score projection remains separate.
- Generic compatibility is insufficient. Flower Pot was the clearest violation and is removed from Four of a Kind.
- Advanced hand Bonds may inherit small support from prerequisite mechanics (Duo/Trio, Shortcut/Four Fingers/Smeared), because those components genuinely improve feasibility of the advanced hand, but their weights stay below dedicated payoff engines.
- Tarot and Planet remain Bonds because sustained generation/access changes acquisition and deck/hand development over the run. Their R4/R5 rank does not itself imply scoring-engine status.
