Canonical component/state -> Bond contribution values after Catalogue Audit Pass 3 and post-freeze Joker-coverage corrections. Architecture is in `BALATRO_STRATEGY_SYSTEM.md`; identities/unlocks are in `BALATRO_STRATEGY_CATALOGUE.md`.

## Rules

- One weighted contribution pool per Bond; contributors are additive alternatives, never sequential rank keys.
- Rank measures development only; realization and Build Health remain separate.
- Multi-Bond contribution is intentional only when a component genuinely develops each axis.
- Hard-unlock Bonds return `LOCKED` when the defining payoff is absent.
- Generic enabling mechanics do not receive quota merely because they can participate.
- R4/R5 remain high-authority states and must be reachable only through legitimate deep commitment.
