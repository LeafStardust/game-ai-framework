# Balatro Strategy Contributions

Canonical home for the component -> strategy-track contribution matrix. This document supersedes `BALATRO_STRATEGY_RELATIONSHIPS.md`.

## Status

**Not yet formulated.**

Do not copy the old Gold/Silver/Bronze table here as though it were the new system. The strategy catalogue must be audited and frozen first.

The old relationship catalogue and runtime tests remain migration evidence. Once the accepted strategy tracks are defined, every relevant Joker/component will be re-audited from first principles for contribution to every applicable track.

## Target data

For each component:

```text
Component
  Track A -> contribution quota
  Track B -> contribution quota
  Track C -> contribution quota
```

A component may advance multiple tracks simultaneously. Contribution means genuine mechanical advancement of that track, not a vote for which single global strategy should win.

The contribution scale and track-rank thresholds will be chosen only after the catalogue is known well enough to inspect the resulting distribution. Old Gold/Silver/Bronze/Banned values must not be mechanically translated.

Conflicts and cross-track synergies are separate composition data, though component-level hard incompatibilities may be represented where required by implementation.
